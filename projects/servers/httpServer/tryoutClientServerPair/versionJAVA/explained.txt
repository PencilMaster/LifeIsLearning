======= GENERAL KNOWLEDGE =======

Java Socket mapping:
 - TCP (stream): ServerSocket + Socket (or NIO: ServerSocketChannel + SocketChannel)
 - UDP (datagram): DatagramSocket (or NIO: DatagramChannel)
 - Multicast (UDP): MulticastSocket (subclass of DatagramSocket)
 - There's no public Java API for raw sockets (we'd need JNI/JNA)
